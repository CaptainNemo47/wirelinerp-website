Getting Started

Everything you need before entering WireLineRP

1. Join the Discord

Join the official WireLineRP Discord to stay updated, access applications, announcements, support, and community information.

2. Read the Server Rules

Review the server rules before playing. Understanding the rules will help you avoid unnecessary warnings and improve roleplay for everyone.

3. Install FiveM

Make sure FiveM is installed and connected to a legitimate copy of Grand Theft Auto V.

4. Create Your Character

Create a realistic character with a believable name, appearance, and background that fits the WireLineRP environment.

5. Learn the Keybinds

Review the server keybinds before getting involved in serious roleplay situations so you know how to interact with vehicles, menus, jobs, and other players.

6. Learn the Basic Commands

Familiarize yourself with the most commonly used server commands, including communication, roleplay, and support commands.

7. Start Your Story

Find employment, meet other players, explore businesses, and begin building your character's story inside WireLineRP.

8. Need Help?

If you run into an issue, use the appropriate support channels in Discord or contact available staff.
